# Employee Management System Application

This is the backend of the Employee Management System, where a user can register and log in using **JWT authentication**. The user can create multiple employees and assign tasks to them. The user can also edit both employees and tasks.

---

## Packages Used

1. **Express.js** – for routing and controllers  
2. **Nodemon** – for auto-reloading during development  
3. **JWT** – for token-based authentication  
4. **Bcrypt.js** – for password hashing and salting  
5. **dotenv** – for environment variables  

---

## Database

Using **MongoDB Cloud** for data storage.

---

## Schemas

- **User Schema**  
- **Employee Schema**  
- **Task Schema**
